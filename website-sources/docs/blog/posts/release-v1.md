# RecoveryBox v1.0 Released

We're excited to announce the first stable release of RecoveryBox!

## What's New

- Full offline Wikipedia access via Kiwix
- WiFi Access Point with automatic routing
- BRouter integration for offline route calculation
- OpenWebRX Plus for SDR radio reception
- Meshtastic web client and BRouter map daemon
- Web-based terminal console
- Service monitoring with rbstatus

## Installation

```bash
git clone https://github.com/mr-dgidgi/recoverybox.git
cd recoverybox
sudo ./recovery_box_install.sh
```

Follow the prompts to select your language and wait for the installation to complete.

!!! tip "Full Install Time"
    A complete installation with French map data takes approximately **4-5 hours** with a good internet connection.
