RecoveryBox

Offline emergency server for essential resources. Wikipedia, maps, radio, Meshtastic — all without internet.

Documentation Blog

What's Inside

:material-wikipedia:

Offline Wikipedia

Kiwix serves Wikipedia offline via Docker. French and English content available through ZIM files.

:material-wifi:

WiFi Access Point

A local WiFi network created via Docker, providing connectivity to all services without internet.

:material-map:

Offline Maps

BRouter for route calculation, tileserver-gl for vector/raster map rendering — fully offline capable.

:material-radio:

SDR Radio

OpenWebRX Plus for receiving radio frequencies via RTL-SDR USB dongles.

:material-message-alert:

Meshtastic

Web client for Meshtastic nodes + daemon for BRouter map integration.

:material-file-document:

PDF Library

Survival documents collection served via library.recovery.box.

:material-clock-outline:

GPS Time Sync

Chrony configured for precise time via GPS — essential for time-critical operations.

:material-console:

Web Console

Terminal access directly from the browser, plus rbstatus for service monitoring.

Installation

  1. Mount a partition to /data 
    mount /dev/sda1 /data
  2. Run the installer as root 
    sudo ./recovery_box_install.sh
  3. Select your language — English, French, or both
  4. Wait for installation — expect 4-5 hours for a full install with French map data
  5. Reboot to activate all services

System Requirements

RecoveryBox is designed for amd64 Debian systems. See debian13-preseed-RB for base system configuration.

Infrastructure

Apache2
Serves all web services through a unified interface.
Docker
Containers for Kiwix, hotspot, OpenWebRX, BRouter, tileserver-gl and planetiler.
iptables
Customizable firewall rules via iptables.sh.
Web Console
Terminal available via the web browser.
rbstatus
Service and network status monitoring.
service-manager
Utility to manage and monitor all services.
MkDocs
Technical wiki for services and tools documentation.
