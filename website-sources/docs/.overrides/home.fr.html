Installation

  1. Montez une partition sur /data 
    mount /dev/sda1 /data
  2. Lancez l'installeur en tant que root 
    sudo ./recovery_box_install.sh
  3. Choisissez la langue — anglais, français, ou les deux
  4. Attendez l'installation — prévoyez 4 à 5h pour une installation complète avec cartographie de la France
  5. Redémarrez pour activer tous les services

Configuration requise

RecoveryBox est conçu pour les systèmes Debian amd64. Consultez debian13-preseed-RB pour la configuration de base du système.

Infrastructure

Apache2
Met à disposition tous les services web via une interface unifiée.
Docker
Conteneurs pour Kiwix, hotspot, OpenWebRX, BRouter, tileserver-gl et planetiler.
iptables
Règles de pare-feu personnalisables via iptables.sh.
Console Web
Terminal accessible via le navigateur.
rbstatus
Supervision des services et de l'état réseau.
service-manager
Utilitaire pour gérer et superviser tous les services.
MkDocs
Wiki technique pour la documentation des services et outils.
